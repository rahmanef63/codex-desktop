Root causes worth not rediscovering:

- `collaboration` namespace is flattened by the gateway's Responses→Chat translator for
  non-OpenAI upstreams → sub-agents die with `unsupported call: collaboration`.
- Images through a non-OpenAI upstream **swap the model** to `kimi-k2.7-code` and tokenise the
  base64 as text (~87× cost). A 2.3 MB screenshot: 17,274 tokens on `cx/*`, ~2.6M on `ctx/*`.
- Windows sandbox banner ("Couldn't check Windows setup") is cosmetic.
  `HKLM\SOFTWARE\OpenAI\Codex\WindowsSandboxService` binds provisioning to one `CODEX_HOME`.
  Do not edit that registry key; it strips the sandbox from the real account.
- `Access is denied (os error 5)` on plugin cache = `chrome@openai-bundled` enabled in the clone.
  Chrome launches `extension-host.exe` from inside the cache directory and Windows locks it.
